# Автономное аварийное TFTP-восстановление Tenda AC10 V1.0

## 1. Гарантия неразрушающего «раскирпичивания» без пайки

Главное инженерное достоинство архитектуры маршрутизатора Tenda AC10 V1.0 заключается в надежной изоляции начального загрузчика.

- Первичный загрузчик **Realtek Booter (Stage 1 и Stage 2)** расположен в защищенных начальных секторах флеш-памяти (`0x00000000 - 0x00020000`, 128 КБ).
- Процедуры обновления прошивки (как через веб-интерфейс, так и по TFTP) физически обращаются только к области ядра и файловой системы (`0x00030000 - 0x007E0000`).
- **Следствие:** Никакие сбои питания при обновлении, неудачные сборки OpenWrt или повреждения файловой системы **не способны стереть загрузчик**. Роутер невозможно необратимо окирпичить программным путем! Для полного восстановления работоспособности не требуются паяльник, разборка корпуса, адаптеры USB-UART или программатор CH341A.

```
+-----------------------------------------------------------------------------------+
|               5 этапов аварийного TFTP-восстановления                             |
|                                                                                   |
|  [Этап 1: Подключение кабеля]      --> Сетевой кабель ПК в порт LAN 1             |
|                                        (Синий порт WAN обесточен - не включать!)  |
|                                                                                   |
|  [Этап 2: Настройка сети ПК]       --> Статический IP: 192.168.1.100 / 24         |
|                                                                                   |
|  [Этап 3: Запуск Disaster Mode]    --> Зажать Reset -> Вставить питание 12V       |
|                                        Держать 15 секунд -> Отпустить             |
|                                                                                   |
|  [Этап 4: Автономная прошивка]     --> Запуск run_emergency_recovery.bat          |
|                                        (Передача TFTP на 192.168.1.6:69)          |
|                                                                                   |
|  [Этап 5: Авто-перезагрузка]       --> Ожидание 60с (Watchdog Reboot)             |
|                                        Возврат сетевой карты в DHCP -> Готово!    |
+-----------------------------------------------------------------------------------+
```

## 2. Пять критических правил аварийного режима Realtek

Прежде чем приступать к прошивке, обязательно изучите 5 аппаратных правил, выявленных при реверс-инжиниринге загрузчика:

1. **Правило 1: Кабель строго в порты LAN 1, LAN 2 или LAN 3.**
   *Причина:* В коде инициализации свитча (`0x8000ED48`) загрузчик аппаратно обесточивает приемопередатчик порта 3 (синий порт WAN). Если кабель включен в WAN, сетевая карта компьютера даже не поднимет физический линк!
2. **Правило 2: Статический сетевой адрес ПК — строго `192.168.1.100`.**
   *Причина:* Сервер TFTP в загрузчике жестко зашит на адрес `192.168.1.6` с маской `255.255.255.0`. Загрузчик не выдает адреса по DHCP.
3. **Правило 3: Кнопку Reset/WPS удерживать ровно 15 секунд при включении.**
   *Причина:* Загрузчик опрашивает кнопку Reset (`GPIO 54`) в течение стартового окна. Удержание кнопки переводит плату в режим бесконечного ожидания прошивки по TFTP.
4. **Правило 4: НИКОГДА не проверяйте доступность роутера через `ping`!**
   *Причина:* В IPv4-парсере загрузчика (`0x80001010`) нет кода обработки протокола ICMP. Все входящие эхо-запросы безусловно сбрасываются. Роутер в режиме TFTP **никогда не отвечает на ping**, но мгновенно принимает пакеты TFTP по UDP порту 69.
5. **Правило 5: Использовать только монолитный образ `cr6c`.**
   *Причина:* Из-за фатального бага обнуления `$s7` (`0x80001C2C`) многосегментные образы (`cs6c` + `hsqs`) затирают ядро. Используйте наш проверенный образ `Tenda_AC10_V1_Stock_TFTP_Recovery.bin` или `tenda-ac10-v1-hybrid-openwrt-4.14-factory.bin`.

## 3. Автоматическое восстановление в Windows (Скрипт 1 клика)

В составе репозитория поставляется 100% автономный офлайн-пакет на Python, который самостоятельно перенастраивает сетевую карту, обнаруживает роутер по ARP, передает прошивку и возвращает настройки сети на место.

### Инструкция:
1. Соедините сетевую карту ПК патч-кордом с портом **LAN 1** роутера.
2. Обесточьте роутер (выдерните круглый штекер питания 12V).
3. Возьмите тонкий предмет (скрепку или зубочистку), зажмите кнопку **`RST/WPS`** на задней панели.
4. Не отпуская кнопку, вставьте штекер питания.
5. **Удерживайте кнопку ровно 15 секунд**, затем отпустите (светодиод SYS должен погаснуть или мигать в медленном цикле).
6. Запустите командный файл от имени администратора:
   ```cmd
   tools\autonomous_recovery\run_emergency_recovery.bat
   ```
7. Скрипт отобразит пошаговый прогресс:
   ```text
   [INFO] Настройка сетевого адаптера: 192.168.1.100/24...
   [INFO] Опрос загрузчика 192.168.1.6 по протоколу ARP...
   [SUCCESS] Обнаружен Realtek Booter (MAC: 50:0F:F5:00:00:01)
   [INFO] Передача прошивки по RFC 1350 TFTP (Блоки по 512 байт)...
   Progress: [########################################] 100% (7,588,884 байт)
   [SUCCESS] Образ успешно принят загрузчиком.
   [INFO] Ожидание записи во Flash-память и срабатывания аппаратного Watchdog...
   [SUCCESS] Роутер успешно перезагрузился!
   [INFO] Восстановление сетевых настроек ПК (DHCP)...
   ```
8. Подождите около 60 секунд. Роутер перезагрузится и поднимет штатную сеть.
9. Откройте браузер и перейдите по адресу: **`http://192.168.0.1`**.

## 4. Ручное восстановление через Tftpd32 / Tftpd64 (Windows)

Если вы предпочитаете выполнять процесс вручную с использованием сторонних утилит:

1. Скачайте портативную версию утилиты **Tftpd32** или **Tftpd64**.
2. Откройте **Панель управления Windows** -> **Сетевые подключения** -> выберите вашу сетевую карту -> Свойства -> **IPv4**:
   - IP-адрес: `192.168.1.100`
   - Маска подсети: `255.255.255.0`
   - Основной шлюз: `192.168.1.6`
   *(Временно отключите Брандмауэр Windows, чтобы он не блокировал UDP-пакеты подтверждений ACK)*.
3. Переведите роутер в Disaster Mode (удержание Reset 15 секунд при подаче питания).
4. Запустите `tftpd64.exe`:
   - В выпадающем списке **Server interfaces** выберите ваш адаптер: `192.168.1.100`.
   - Перейдите на вкладку **Tftp Client**.
   - Поле **Host**: введите `192.168.1.6`.
   - Поле **Port**: `69`.
   - Поле **Local file**: нажмите `...` и выберите образ `Tenda_AC10_V1_Stock_TFTP_Recovery.bin` (или образ `tenda-ac10-v1-hybrid-openwrt-4.14-factory.bin`).
   - Поле **Remote file**: оставьте пустым или укажите любое имя (загрузчик Realtek игнорирует имя файла).
   - Поле **Block size**: оставьте `Default` (512 байт).
5. Нажмите кнопку **Put**.
6. В окне программы отобразится шкала передачи файла. Передача ~7.5 МБ занимает 8–15 секунд.
7. **НЕ ВЫКЛЮЧАЙТЕ ПИТАНИЕ!** После завершения передачи загрузчик стирает блоки SPI Flash и записывает образ (`AutoBurn`). Через 40–50 секунд сработает аппаратный Watchdog (`0xB8003000`), и роутер сам уйдет в перезагрузку.
8. Верните настройки сетевой карты в режим «Получать IP-адрес автоматически».
9. Зайдите в веб-интерфейс: `http://192.168.0.1`.

## 5. Восстановление в операционных системах Linux / macOS

В среде Linux аварийная прошивка выполняется одной стандартной консольной командой без установки графических пакетов:

1. Настройте сетевой интерфейс (например, `eth0`):
   ```bash
   sudo ip addr add 192.168.1.100/24 dev eth0
   sudo ip link set eth0 up
   ```
2. Переведите роутер в Disaster Mode (зажать Reset на 15 секунд при включении).
3. Проверьте обнаружение по ARP:
   ```bash
   arping -I eth0 -c 2 192.168.1.6
   ```
4. Отправьте бинарный образ командой `tftp`:
   ```bash
   echo -e 'binary\nput Tenda_AC10_V1_Stock_TFTP_Recovery.bin\nquit\n' | tftp 192.168.1.6
   ```
5. Дождитесь подтверждения отправки всех блоков и перезагрузки роутера.

## 6. Что делать после завершения прошивки

- Если вы прошивали **Stock Recovery (`Tenda_AC10_V1_Stock_TFTP_Recovery.bin`)**:
  Роутер поднимет стандартную заводскую прошивку. Доступ в панель: `http://192.168.0.1`. При первом входе задайте пароль администратора. Рекомендуется сразу применить профиль `RouterCfm_optimized_sanitized.cfg` для отключения шпионских служб.
- Если вы прошивали **Hybrid OpenWrt (`tenda-ac10-v1-hybrid-openwrt-4.14-factory.bin`)**:
  Роутер запустит OpenWrt. Панель управления LuCI доступна по адресу `http://192.168.0.1`. Вход по умолчанию: логин `root`, пароль пустой.
