Отличное замечание, огромное спасибо за внимательность!

Действительно, в стартовом скрипте первоначальной настройки [font="Courier New"][b]99-dir842-m5[/b][/font] веб-сервер LuCI ([font="Courier New"][b]uhttpd[/b][/font]) по умолчанию жестко привязывался к адресу [font="Courier New"][b]192.168.0.1:80[/b][/font].
Из-за этого при смене рабочей подсети LAN или переводе роутера в режим прозрачной точки доступа / моста (Access Point / Dumb AP / Bridge с получением адреса по DHCP), когда адрес [font="Courier New"][b]192.168.0.1[/b][/font] на интерфейсе исчезал, веб-интерфейс переставал открываться по новому IP, хотя интернет и доступ по SSH продолжали работать без проблем.

[b]Что сделано и обновлено:[/b]
1. В исходниках сборочного скрипта и во всех собранных образах прошивки ([font="Courier New"][b]factory[/b][/font], [font="Courier New"][b]sysupgrade[/b][/font], [font="Courier New"][b]webupgrade[/b][/font]) бинд веб-сервера переведен на все интерфейсы:
[code]uci -q delete uhttpd.main.listen_http
uci add_list uhttpd.main.listen_http='0.0.0.0:80'
uci add_list uhttpd.main.listen_http='[::]:80'
uci set uhttpd.main.rfc1918_filter='1'
uci commit uhttpd[/code]
Теперь панель управления LuCI автоматически открывается на любом назначенном IP-адресе в любых режимах работы (роутер, точка доступа, клиент).
2. [b]Безопасность со стороны провайдера (WAN):[/b] внешний порт [font="Courier New"][b]eth0.1[/b][/font] по-прежнему намертво закрыт правилом файрвола [font="Courier New"][b]zone_wan input REJECT[/b][/font] (и аппаратной изоляцией Switch Port 3 в gw_prog), веб-интерфейс наружу в интернет не светит.
3. Все образы прошивки, контрольные суммы SHA-256 и автономные архивы на [url=https://github.com/ccsimplyspolit/tenda-ac10-v1-hybrid-openwrt/releases/tag/v4.14.187-r3-ac10-hybrid]GitHub Releases (v4.14.187-r3-ac10-hybrid)[/url] полностью перезалиты и обновлены.

[b]Как исправить у себя на уже установленной прошивке за 10 секунд без перепрошивки (по SSH):[/b]
Подключитесь по SSH ([font="Courier New"]root@192.168.0.1[/font] или по текущему IP роутера) и выполните:
[code]uci -q delete uhttpd.main.listen_http
uci add_list uhttpd.main.listen_http='0.0.0.0:80'
uci add_list uhttpd.main.listen_http='[::]:80'
uci set uhttpd.main.rfc1918_filter='1'
uci commit uhttpd
/etc/init.d/uhttpd restart[/code]
После этого LuCI мгновенно становится доступен на любом новом адресе роутера.
